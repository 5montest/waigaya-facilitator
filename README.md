# ワイガヤのAI進行・記録係「我ヶ谷」

Discordの話し合いを文字起こしし、根拠付きの議事録下書きを作るMVPです。AIが会議で話す機能は別設定で、既定の「議事録のみ」では音声発言しません。議事録は人が確認し、指定先への共有操作をするまで公開しません。

AI処理はOpenAIのみです。ホスト端末がDiscord接続・発話検知・SQLite保存を担当し、文字起こし・議事録生成・AI音声はクラウドで処理します。JetsonやSonioxの登録は不要です。

このREADMEは改善実装ブランチに対応します。稼働中の旧Botはこの作業で更新していません。新コマンドを使うには、[移行手順](discord-setup.md)に従ってサーバーとBotを更新してください。

## 起動

Node.js 24.17以上を使います。プロジェクトのルートで実行します。

```bash
npm ci
cp .env.example .env.local
```

`.env.local` に `OPENAI_API_KEY_FILE`（ワークスペース内のキーファイル）または `OPENAI_API_KEY` を設定します。既存ファイルを指定すればキーを複製せずに利用できます。ブラウザへキーは渡しません。

ブラウザだけで使う場合は `npm start` で http://127.0.0.1:8765 を開きます。別端末のマイクには[LAN設定](docs/lan-setup.md)のHTTPSが必要です。稼働中の環境ではプロセスを重複起動しないでください。

Discordでは別途 `.env.discord.example` を `.env.discord` にコピーし、Application ID・サーバーID・Botトークンのファイルを設定します。Botと会議サーバーの接続にも認証が必要です。

```bash
# 接続認証ファイルを生成。既存ファイルは上書きしない
npm run discord:auth
```

両方の環境ファイルに同じ `WAIGAYA_DISCORD_SERVICE_TOKEN_FILE` を設定してから起動します。詳細と旧記録の移行は[設定手順](discord-setup.md)を参照してください。

```bash
# 招待URLを表示／コマンドを登録
npm run discord:setup
npm run discord:setup -- --register
# 別々のターミナルで起動
npm start
npm run discord
```

BotにはVCの閲覧・送信・接続・発言と、公開先の閲覧・送信・ファイル添付を許可します。管理者権限やMessage Content Intentは不要です。

## Discordでの使い方

通話に入り `/waigaya start` でモードを選びます。モード選択が終わり、送信・保存先を通知するまでは記録しません。

| モード | AIの音声 |
|---|---|
| 議事録のみ（既定） | 常にOFF。askも文字回答 |
| 呼びかけた時だけ | askで `voice:true` を指定した時だけ |
| AIワイガヤ | 介入条件を満たし、モデルが必要と判断した時だけ |

| コマンド | 動作 |
|---|---|
| `status` / `help` | 状態・保存・障害・使い方を確認 |
| `mode` | モード変更。会議IDと記録は継続 |
| `ask` / `summary` | 質問への回答／ここまでの根拠付き要約 |
| `quiet` | AI音声だけ停止。記録は続ける |
| `pause` / `resume` | 記録の一時停止／明示再開 |
| `finish` | 確認して会議終了。議事録下書きを生成 |
| `minutes` | 最近の会議を選び、原本・議事録・JSONを本人だけに表示。訂正・再生成・確認 |
| `publish` | 確認済みの版を、開始時に指定した公開先へ共有 |

`/waigaya start output_channel:` で共有先を選べます。未指定の場合も議事録は保存され、非公開で取得できます。終了案内は開始者へのDMで、本文は自動投稿しません。DMを受け取れなくても `minutes` から確認できます。

人間が全員退出すると3分の猶予に入り、戻れば同じ会議を続けます。猶予を過ぎると退出・終了・議事録生成へ進みます。終了や生成が競合しても重複生成・重複投稿を避けます。再起動後は一時停止で復旧し、録音は明示的な再開を待ちます。

人が話している間はAI音声を始めず、人の声を検知すると再生を止めます。古い自律候補は会話更新・訂正・モード変更で取り消し、中断した音声は自動再開しません。

会議の操作・記録閲覧・共有は開始者、サーバー管理者、設定した管理ロールに限ります。元VCの閲覧・接続権限も必要です。旧 `stop` はAIだけ停止、`leave` は確認後に終了、`auto` はモード切替／AI停止の互換操作として残します。以前の自律ON開始・ask音声の既定は変更しました。

## モデルと保存

| 役割 | モデル |
|---|---|
| Discord文字起こし | `gpt-transcribe` |
| 議事録・質問・整理 | `gpt-6.1-sol` |
| 音声生成 | `gpt-4o-mini-tts`、声 `marin` |

SQLiteの正本は `data/waigaya.sqlite` です。文字起こし・訂正履歴・会議状態・議事録の版・確認者・公開結果・API使用量を保持します。元音声のファイル保存と記録の自動削除は行いません。

議事録はMarkdown・JSON、原本は別のMarkdownで取得できます。各重要事項は発言IDとrevisionを参照し、AIの決定候補と人が記録した決定を区別します。訂正後の旧版は要再確認となり、再生成できます。確認済み・公開済みの版は履歴に保持します。

長い会議は根拠付きの分割要約を統合し、進行用の文脈は直近原文と長期要約を使います。SQLiteの原本は切り捨てません。生成・音声・投稿の失敗で原本を削除せず、保存自体に失敗した時は未保存の可能性を表示します。

Discord記録のHTTP・WebSocket・ファイル取得は、ループバックからの認証済みBotに限定します。ブラウザは独立した会議の編集・保存・3モード・一時停止・終了に対応します。Discord会議のブラウザ閲覧は、個人認証を実装するまで提供しません。独立したブラウザ会議は、従来の許可されたLAN内で共有利用するため、信頼できる利用者だけに公開してください。

## 検証

```bash
npx playwright install chromium
npm test

# 設定・比較対象の表示。APIは呼ばない
npm run compare
# 実APIを呼ぶ比較・接続確認。料金が発生する
npm run compare -- --run
npm run smoke:openai
```

自動テストは95件です。既存の制御・保存・HTTP/WebSocket・ブラウザ・音声変換に加え、モード別の音声禁止、退出猶予、終了競合、根拠訂正、復旧、認可、公開の重複防止を確認します。架空会話の議事録を実OpenAI APIで生成し、スキーマと根拠参照を検証しました。

新しい操作の実Discord通話、DM・添付・権限、1時間以上の品質・費用、音声停止までの時間は未確認です。[手動チェック](docs/manual-acceptance.md)で別途確認します。同時1会議の制限と音量ベースの割り込み判定は維持しています。残るP1・P2要件は[差分・残課題](docs/improvement-report.md)に記載しました。

## 構成と秘密情報

| 場所 | 内容 |
|---|---|
| `src/discord/` | Bot、音声入出力、自律検討、アクセス制御 |
| `src/` | 会議サーバー、状態制御、議事録生成、モデル、SQLite |
| `public/` | ブラウザ画面と音声入力 |
| `scripts/` | Discord設定・認証・旧記録移行・比較・接続確認 |
| `test/` / `eval/` | 自動テストと比較用会話 |
| `docs/` | 設計・選定・操作・検証・残課題 |

`.env.local`・`.env.discord`、`seacret/`・`secrets/`、`data/`、`results/`、証明書・秘密鍵はGit管理から除外します。会議記録・API応答の原本・キーはGitHubへ送信しません。
