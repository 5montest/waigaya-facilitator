## 2026年10月14日の本筋設定・脱線通知

開始時の任意purpose、声による本筋の設定・変更・確認を追加した。目的・比較軸・除外事項は自由文をそのまま保存し、設定確認はLLMを使わず短く読み返す。開始者・管理担当者だけが設定を変更でき、ほかの参加者も読み返しを頼める。原発言のIDとrevision、指定者、設定履歴をSQLiteに保持する。会議名や確認済み決定は変更しない。

通常の呼びかけ応答では、本筋を設定しても自動発言を始めない。明示的な「脱線したら声をかけて」で有効にした場合だけ、既存の沈黙・文脈・間隔制御を通して本筋への短い提案を出す。一般の進行質問は採用しない。厳密なminutesとquietは音声禁止を維持し、本筋の設定・確認は文字だけにする。原発言訂正で設定は要再確認となり、古い設定を回答・自動介入に使わない。再生成議事録にも要再確認を注記する。

自動テスト173件成功・失敗0（この機能の12件追加、模擬Discord＋実ローカルHTTP／SQLite／TTSを含む）。実gpt-6.1-solでも合成文字会話3件を確認：関連する比較はhold（4,439ms）、無関係な旅行の話が続く場合はsummary（5,501ms）、すでに本筋へ戻った会話はhold（2,856ms）。当該3回のLLM使用量からの推定費用は合計$0.006978で、STT・TTS・総請求額の測定ではない。少数の合成ケースであり、実会議の脱線検出精度を証明するものではない。

既存の会議・公開版は保持し、破壊的なSQLiteテーブル変更はない。配列保存対象にbriefHistoryを追加したため、ロールバックは旧コードと更新前DBの組み合わせを使う。導入時はサーバーとBotの両方を更新し、コマンドを再登録する。稼働中Bot・サーバーの停止／更新、実Discordへの追加投稿、mainへのマージは行っていない。本筋設定の人の実通話確認は未実施。

## 2026年10月14日の議事録表示修正

投稿本文の日時を `2026/10/13 22:04〜22:07（日本時間）` に統一し、同日内の終了日は省略した。見出しと箇条書きで項目を分け、空の項目を省略する。人の確認・合意を保証しないことと、確認済み決定がないことは表示に残す。参加者名の末尾に付けていたDiscordユーザーIDも本文から除いた。

送信照合IDは最初の添付の管理情報へ移し、本文には出さない。添付Markdownのバイト列・ハッシュ・人の承認履歴は変更しない。新方式の添付情報と旧本文IDの両方を照合できる。新方式での送信後DB障害・異なる予約の拒否を含め、自動テスト161件成功・失敗0。

既存の合成音声テスト投稿（版1・版2）だけを実Discordで表示更新し、添付IDが変わらないこと、本文に内部IDがないこと、実Discordから取得した添付情報で投稿URLを照合できることを確認した。新たな会議・議事録版・親投稿は作らず、稼働中Botの停止・更新やmainへのマージは行っていない。人の実通話確認は引き続き未実施。

## 主なコード変更

- `src/discord/fixed-policy.js` / `config.js` / 環境ファイル例：固定先・応答方針・猶予・自動公開・呼称設定、IDと実チャンネル検査。
- `src/discord/addressing.js` / `bot.js` / `bridge.js`：STT確定イベントの配線、依頼者と発言revision、排他・再送抑止、声からの回答と一回開始・退出。
- `src/models.js` / `controller.js`：直接質問用の情報回答プロンプト、既存構造化出力、音声依頼の文脈・TTL・再生世代、AI発言の根拠除外。
- `src/discord/completion.js` / `server.js` / `meeting.js`：DBに保存したジョブの走査、再起動時の無人猶予・終了再開。ワーカー自身はVC接続や録音を行わない。
- `src/publication.js` / `minutes.js` / `discord/minutes-publication.js`：固定・通知済みポリシーの公開検査、未確認ラベルとタグ、予約した本文の固定、人の確認別版、同じ投稿の更新。
- `src/state-sync.js`：voiceRequestsを既存の変更行保存・差分配信へ追加。DBのテーブル削除や履歴削除はない。
- `src/discord/commands.js` / `scripts/discord-setup.js`：固定運用のコマンド登録、汎用選択を非表示、非常用endと旧stopの区別。
- `test/fixed*.test.js` / `test/helpers/fixed.js`：模擬Discordの音声受信、実Opusデコード・発話検知、ローカルHTTP・WebSocket・SQLiteを通した結合・復旧テスト。

10月9日時点では新しい確定発言で旧候補を破棄していた。10月13日に、直接依頼だけ一回最新文脈で再検討する方式へ変更した。会話が続けて変わる場合は無制限に再生成せず、必要なら再度呼びかける。曖昧な呼称は追加LLMを呼ばず見送るので、誤応答と費用を抑える。

## 検証・移行

着手時の既存121件を維持し、固定運用の新しいケースを追加した。[検証記録](validation.md)に実際の件数・コマンド・CIを記載する。新版の実OpenAI API・実Discord通話／投稿は実行していない。Secrets不要の既存CIで新ケースも走る。[手動受け入れ](manual-acceptance.md)を実通話のリリースゲートにする。

旧サーバーが公開ファイルを読んでいるため、別のgit worktreeで編集・クリーン導入・テストした。旧サーバーは停止も更新もしていない。以前の退出依頼で旧Botは通常停止済みであり、新Botを勝手に起動していない。

固定設定・終了ジョブ・確認属性は既存JSONへの追加。voiceRequestsは既存session_partsの追加配列。破壊的DB変更はない。ただし旧コードが新しいDBを読める保証はないので、停止バックアップと旧コード＋更新前DBでのロールバックを必須にする。[導入・ロールバック](../discord-setup.md)を参照。
