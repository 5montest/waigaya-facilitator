# LAN公開とキー設定

以下は2026年10月9日時点の稼働環境の設定である。別の端末で構築する場合はIPアドレスと許可範囲を環境に合わせる。

現在はLAN内へ公開して起動している。

- 文字入力・AIへの検討依頼： http://192.168.8.10:8765
- マイク・音声再生も使う画面： https://192.168.8.10:8766
- 初回の証明書設定： http://192.168.8.10:8765/lan

別端末のマイクにはHTTPSが必要です。初回は案内ページから「Waigaya LAN CA」をダウンロードし、端末にインストールして信頼します。[ブラウザのマイク利用条件](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)、[iPhone・iPadの信頼設定](https://support.apple.com/en-us/102390)

同じPCでは http://127.0.0.1:8765 も利用できます。HTTPとHTTPSは別のブラウザ保存領域になるため、会議の選択は別になります。録音開始後は同じ画面で操作を続けます。

HTTPとHTTPSは同じサーバー・データベースを使います。接続元を `192.168.8.0/24` とループバックに限定し、許可したホスト名と同じOriginからの操作だけ受け付けます。LAN内の許可された端末はログインなしで利用できます。ルーターの公開設定は変更していません。

HTTPS用の秘密鍵・証明書は `data/tls/` に保存し、公開するのはCA証明書だけです。サーバー証明書の有効期間は作成から180日です。IPアドレスの変更や証明書の更新時は、証明書と `.env.local` の許可ホスト・サブネット・接続先も更新します。

キーがなくても、文字起こしの追加・修正、人が確認した決定の記録、Markdownの保存を使えます。「想定会話を追加」はテスト用の文章を追加する操作です。

## 既存キーの読み込み

指定された既存ファイルを使うよう `.env.local` を設定済みです。キーの値は複製せず、サーバーのメモリへ読み込みます。ブラウザへは渡しません。SonioxやGoogleの登録・キーはMVPでは必要ありません。

| 設定 | 用途 |
|---|---|
| `OPENAI_API_KEY_FILE` | このワークスペース内の既存キーファイルを指定。現在はこちらを使用 |
| `OPENAI_API_KEY` | 環境変数から渡す場合。両方あるとこちらを優先 |
| `WAIGAYA_OPENAI_VOICE` | 任意。声の初期値は `marin` |
| `WAIGAYA_PORT` | HTTPのポート。初期値は `8765` |
| `WAIGAYA_HOST` | 待ち受けIP。現在は `0.0.0.0` |
| `WAIGAYA_ALLOWED_HOSTS` | LANのIP・ホスト名をカンマ区切りで指定 |
| `WAIGAYA_ALLOWED_NETWORKS` | LANクライアントのCIDRを指定。現在は `192.168.8.0/24` |
| `WAIGAYA_HTTPS_PORT` / `WAIGAYA_HTTPS_URL` | HTTPSのポートと案内先URL |
| `WAIGAYA_TLS_KEY` / `WAIGAYA_TLS_CERT` / `WAIGAYA_TLS_CA` | HTTPSの秘密鍵・サーバー証明書・配布用CA証明書 |

設定例は [.env.example](../.env.example) にあります。設定を変えたらサーバーを再起動します。他社モデルへの自動切り替えや、失敗時の自動再試行は行いません。
