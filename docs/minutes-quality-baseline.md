## 2. 計測方法（再現可能・決定論的）

段階を次のように定義し、同じ原本から機械的に測る。

| 段階 | 定義 | 実体 |
|---|---|---|
| R0 | 確定した人間の発言集合（`final && source!=='ai'`） | `state.utterances` |
| R1 | 現行の structured minutes v1 document | `state.minutesHistory[0].document` |
| R2 | 現行 `minutesMarkdown` の全文 | 公開記録の `publicationMarkdown`（実際に公開された添付） |
| R3 | 現行 `shortMinutes` のDiscord本文 | 修正前実装を固定した `eval/legacy-v1.mjs` で再現（DBに本文は保存されない） |

- 計測器: `scripts/evaluate-minutes.js`（外部APIなし・`node:sqlite` readOnly・出力に発言本文を含めない）。
- R2/R3の固定: 修正前（b5eaf47）の `minutesMarkdown` / `shortMinutes` を `eval/legacy-v1.mjs` にスナップショット。
  R2は実物（公開済み添付）を使用し、再計算結果とsha256が一致することを確認した。
  **R3はDB未保存のため「修正前ロジック再現値」であり、実送信本文そのものではない。**
- 判定基準:
  - 既知facts: 正規化（NFKC・小文字化・空白/カンマ除去）後の文字列一致。別名グループのAND一致。
  - 数値: 単位を基本値へ正規化（例: 30万円→300000円、1,234円→1234円）。意味の正しさは判定しない。
  - 技術名候補: 英数字トークン（2文字以上）の一致。STT誤認識の有無は判定しない。
  - 討議過程: 理由/条件/懸念/比較/検証/決定の**語彙**の出現数（意味判定ではない）。
  - evidence: utteranceIdの存在・revision一致・確定状態のみ（A4の「根拠支持率」とは別物）。
- 決定論性: 現在時刻・乱数・外部APIを使わない。同じ入力から同じJSONを返す。

再現コマンド（実DBが存在する環境）:

```bash
# 修正前ベースラインの再計算（集計値のみ・本文は出力しない）
node scripts/evaluate-minutes.js \
  --db /immich/media/agent-work/20261009-waigaya-fixed-ops/data/live-validation.sqlite \
  --session 84eb2cd9-1d27-43e5-80a9-76c35e9fc363 \
  --renderer legacy-v1 --probes work/baseline/probes.json \
  --json /tmp/baseline.json

# 評価基盤の自己検証（外部API・DB不要）
npm run eval:minutes
node --test test/evaluation.test.js
```
