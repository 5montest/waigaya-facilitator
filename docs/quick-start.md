# 我ヶ谷の使い方

更新日：2026年10月15日

**普段は `/waigaya start` を1回実行するだけです。呼びかけなければ、Botは黙って議事録を作ります。**

## 会議を始めて、終える

1. [会議室A](https://discord.com/channels/1279446749970436236/1279446750498787390)のボイス通話に入ります。
2. Discordのチャット入力欄で `/waigaya start` を実行します。参加者のうち1人だけが操作してください。
3. 「会議を記録しています」の表示を確認してから、普段どおり話します。
4. 終わったら全員退出します。終了や投稿の操作は不要です。

全員退出から3分後に自動終了し、Botも退出します。その後、[議事録（テスト）](https://discord.com/channels/1279446749970436236/1557808517904338995)フォーラムに会議ごとの議事録を投稿します。生成に時間がかかるため、退出と同時に投稿されるわけではありません。

3分以内に戻れば同じ会議を続けます。人が残っている間は、無音でも自動終了しません。Botがオンラインなだけでは記録しません。発言がなかった会議は投稿を省略します。

## 質問するときだけ「ワイガヤ」と呼ぶ

発言の最初に名前を呼んで、そのまま質問してください。

> 「ワイガヤ、今の話をまとめて」
>
> 「ワイガヤ、A案とB案の違いを教えて」

Botが短く音声で返答します。開始した人以外も質問できます。人が話している間は待ち、返答中に人が話し始めたら音声を止めます。中断した続きを勝手に再開しません。

**startだけで、自律的な質問や脱線の指摘を始めることはありません。**

## 会議の本筋は声で伝えられる

開始した人か管理担当者が、目的や比較したいことを伝えます。

> 「ワイガヤ、今日の目的は配線方式を決めること。コストと作業時間を比較したい」

Botが短く読み返し、後の回答・議事録へ引き継ぎます。本筋を設定しただけでは自動発言しません。任意で、startの `purpose` に事前入力することもできます。

| したいこと | 話しかけ方 |
|---|---|
| 本筋を確認 | 「ワイガヤ、今日の目的を教えて」 |
| 本筋を変更 | 「ワイガヤ、本筋をコストの比較に変更して」 |
| 脱線時の声かけを有効化 | 「ワイガヤ、脱線したら声をかけて」 |
| 脱線時の声かけを停止 | 「ワイガヤ、脱線の声かけを止めて」 |

脱線の声かけは必要な場合だけ有効にしてください。先に本筋の設定が必要です。設定変更は開始した人か管理担当者が行い、確認はほかの参加者もできます。次の会議では設定を引き継がず、脱線の声かけもOFFで始まります。

## 議事録を読む・直す

フォーラムの投稿に要約とMarkdownファイルを載せます。表示は **「AI生成・未確認」** です。人の確認や参加者全員の合意を示すものではありません。

開始した人か管理担当者は `/waigaya minutes` から、議事録と文字起こしを本人だけに表示して取得・訂正できます。訂正版は同じフォーラム投稿へ追記し、過去の版も残します。普段は承認ボタンやpublish操作を使う必要はありません。

## 必要なときだけ使う操作

| したいこと | コマンド |
|---|---|
| 記録・回答・投稿の状態を確認 | `/waigaya status` |
| 記録を一時停止 | `/waigaya pause` |
| 記録を再開 | `/waigaya resume` |
| AI音声だけ停止し、記録は継続 | `/waigaya quiet` |
| 3分待たず、会議をすぐ終了 | `/waigaya end` |

操作は開始した人か管理担当者が行います。旧stopはAI音声だけを止める操作で、会議終了ではありません。quietの後にresumeを使っても、AI音声は再開しません。同じ会議で音声を戻したい場合や、投稿エラー・記録障害が出た場合は管理者へ相談してください。

記録中の音声はOpenAIへ送ります。元の音声ファイルは保存せず、文字起こしを保持します。終了後の議事録はフォーラムを閲覧できる全員に自動公開します。公開したくない内容を話す前にpauseを使ってください。

詳しい訂正手順・権限・トラブル対応は [利用マニュアル](user-manual.md) に記載しています。管理者が厳密な「議事録のみ」プリセットを選んだ場合は、呼びかけても音声は出しません。この説明書の通常設定は「呼びかけたときだけ応答」です。
